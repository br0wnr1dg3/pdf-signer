# PDF Signer

Sign PDFs locally on your Mac. No accounts, no uploads, no Adobe.

## Run
Double-click `open.command` (or `npm start` then visit http://localhost:8765).

## Use
1. Open / drop a PDF.
2. **Sign** — draw once (or upload a PNG). It's saved in your browser for next time.
3. **+ Signature / + Date / + Text** — drag to move, drag the blue corner to resize, double-click text to edit, `Delete` to remove.
4. **Save signed PDF** — downloads `<name>-signed.pdf`. The original is untouched.

## Tests
`npm test`

## Known limitations
- No cryptographic/digital signature — this stamps an image and text onto the page, like signing on paper.
- PDFs with a `/UserUnit` other than 1 (rare, large-format drawings) are assumed to be 1.
- Text must be representable in Helvetica (WinAnsi). Other characters are removed on commit, with a toast.
- `open.command` leaves the local server running after you close the browser. Stop it with `lsof -ti tcp:8765 | xargs kill`.
- The page is rendered once per open at the current display density; moving the window between Retina and non-Retina screens does not re-render.
